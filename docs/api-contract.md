# API contract for client implementations

Base URL http://localhost:4000/api. Browser fetch uses credentials: include. All responses wrap data as `{success:true,data:T}`. Failures `{success:false,message,errors:[]}`. All monetary integers are paisa: divide by 100 for PKR display. All dates ISO. All list responses `Paginated<T>`.

GET /content -> SiteContent (settings, sections, menus, categories, collections). Section config keys: image, mobileImage, eyebrow, ctaText, ctaUrl, secondaryText, secondaryUrl, background, textColor, productIds, collectionSlug, categorySlug, gender, columns, imagePosition. Types: hero, products, categories, editorial, campaign, newsletter, shop-the-look, announcement, custom, video. CMS config is display data, never executable HTML/scripts.
GET /products?q=&category=&collection=&gender=&size=&color=&minPrice=&maxPrice=&inStock=&sale=&sort=&page=&pageSize= -> Paginated<Product>. GET /products/:slug -> Product. GET /categories -> Category[]. GET /collections -> Collection[]. GET /campaigns/:slug -> Campaign. GET /pages/:slug -> {title,slug,body,seoTitle,seoDescription}; body is safe structured JSON blocks.
GET /products/:id/reviews -> Paginated<Review>. POST /reviews {productId,rating,title,body}. GET /shipping -> ShippingMethod[].
POST /checkout/quote accepts CheckoutInput without idempotencyKey, returns Quote. POST /checkout accepts CheckoutInput with UUID idempotencyKey, returns Order including accessToken for guest order and optional paymentUrl. GET /orders/:id?token= -> Order. Prices/stock always recalculated on API. COD and BANK_TRANSFER available without credentials; STRIPE only when configured.
GET /payment-methods -> {id,name,description}[]
POST /auth/register {name,email,password}; POST /auth/login {email,password}; both return User and set HttpOnly cookies. POST /auth/logout. POST /auth/refresh. GET /auth/me -> User. POST /auth/forgot-password {email}; POST /auth/reset-password {token,password}; POST /auth/verify-email {token}. POST /auth/resend-verification. GET/PATCH /account/profile {name,marketingOptIn}; POST /account/change-password {currentPassword,password}; POST /account/deletion-request.
GET /account/orders -> Paginated<Order>. GET/POST /account/addresses; DELETE /account/addresses/:id. GET /account/wishlist -> Product[]; POST /account/wishlist {productIds:string[]} merges; DELETE /account/wishlist/:productId. GET /account/cart -> {items:{variantId,quantity}[]}; POST /account/cart {items} merges and caps stock. POST /account/returns {orderId,reason,items:[{orderItemId,quantity}],description}; GET /account/returns.
POST /newsletter {email,source,consent:true}; POST /newsletter/unsubscribe {token}; POST /contact {name,email,subject,message,phone?,orderNumber?}.

Admin: same auth cookies; require ADMIN kind and permissions. GET /admin/dashboard returns live metrics and recent orders. GET /admin/resources -> allowed resource metadata. GET /admin/:resource?page=&pageSize=&q= -> Paginated<record>. POST /admin/:resource and PATCH /admin/:resource/:id validate resource-specific fields. DELETE supported where safe. GET /admin/:resource/:id returns record. GET /admin/:resource/export yields CSV.
Resources: products,categories,collections,campaigns,coupons,discounts,homepage,pages,menus,shipping,taxes,settings,roles,users,reviews,customers,orders,inventory,audit-logs,returns,refunds,newsletter,inquiries,notifications,payments,media,email-templates,abandoned-carts. Metadata describes fields, requiredness, options, defaults, and readOnly. Product editor handles variants/images/collectionIds. Products REST shape matches Product but incoming images [{url,alt,position}], variants [{id?,sku,color,colorHex,size,price?,stock,active}], collectionIds string[].
POST /admin/inventory/adjust {variantId,delta,reason}; POST /admin/orders/:id/status {status,note,trackingNumber?,trackingUrl?}; POST /admin/orders/:id/refund {amount,reason}; POST /admin/returns/:id/status {status,note}; POST /admin/homepage/reorder {ids:string[]}; POST /admin/products/bulk {ids,action:'activate'|'archive'|'delete',categoryId?,collectionId?}; POST /admin/products/import {csv:string}.
POST /admin/media/upload multipart file (10MB image / 50MB video) -> {id,url,alt,mime,size}; storage configuration required. POST /admin/media adds existing media URL. PATCH alt and position via normal metadata editor.
GET /admin/reports -> live sales, products, categories, collections, coupon usage. GET /admin/search?q= -> categorized matches. GET /admin/email-preview/:id -> outbox record, admin only development.
